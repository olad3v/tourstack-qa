# TourStack Test Cases

This document contains the test cases used to verify TourStack functionality.

## Test Case Structure

Each test case should contain:

* Test Case ID - A unique identifier
* Feature - The functionality being tested
* Role - The type of user performing the test
* Steps - The actions performed during the test
* Expected Result - What should happen
* Actual Result - What actually happened
* Result - PASS, FAIL, BLOCKED, or NOT RUN
* Evidence - Screenshot, recording, or other supporting evidence
* Defect - Linear issue ID if the test reveals a defect

## Test Cases

Test cases will be added here as the product is mapped and its functionality becomes clear.
