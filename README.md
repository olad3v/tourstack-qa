# TourStack QA

QA workspace for documenting and testing the TourStack platform.

## Purpose

This repository is used to map the product, document test cases, record test executions, track defects, store testing evidence, and eventually contain automated tests.

## Structure

* `product-map/` — Features and functionality that have been built.
* `test-cases/` — Defined testing scenarios and expected results.
* `test-executions/` — Records of test runs and their results.
* `defects/` — Defects discovered during testing.
* `evidence/` — Screenshots, recordings, and other supporting evidence.
* `automation/` — Automated tests added later.
