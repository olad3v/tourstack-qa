# TourStack Defects

This document keeps a record of defects discovered during testing and links them to their corresponding Linear issues.

## Defect Structure

Each defect should contain:

* Defect ID - A unique identifier
* Test Case ID - The test case that revealed the defect
* Feature - The functionality where the defect was found
* Summary - A short description of the problem
* Severity - The impact of the defect
* Status - The current state of the defect
* Linear Issue - The corresponding Linear issue ID
* Evidence - Screenshot, recording, or other supporting evidence

## Defects

Defects will be added here as they are discovered during testing.
