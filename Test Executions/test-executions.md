# TourStack Test Executions

This document records the results of test cases after they are executed.

## Test Execution Structure

Each execution should contain:

* Test Case ID - The test case being executed
* Date - The date the test was performed
* Tester - The person who performed the test
* Environment - The application or environment where the test was performed
* Result - PASS, FAIL, BLOCKED, or NOT RUN
* Actual Result - What happened during the test
* Evidence - Screenshot, recording, or other supporting evidence
* Defect - Linear issue ID if a defect was discovered

## Test Executions

Test execution records will be added here as test cases are performed.
